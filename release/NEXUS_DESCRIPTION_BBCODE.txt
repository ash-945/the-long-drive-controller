[size=5][b]The Long Drive — Controller Support[/b][/size]

[b]Play The Long Drive with Xbox, PlayStation, and Nintendo controllers, including menus, driving, and object handling.[/b] Automatic button icons, editable bindings, toggle sprint and crouch, and adjustable steering bring the controls together in one mod.

[b]Version 0.6.7 beta • For game v2024.11.26b[/b]

[size=4][b]New in this update[/b][/size]

• [b]Gradual steering:[/b] holding full stick now approaches full lock over time. Releasing or reversing also moves gradually. The new [b]Steering time to full lock[/b] option defaults to [b]0.75 seconds[/b]; higher values turn more slowly.
• [b]Separate curve and speed settings:[/b] the existing sensitivity value is now labelled [b]Steering stick curve[/b]. Existing saved values are preserved. Duplicate native joystick steering is blocked while the mod controls the pad, so it cannot override the ramp; keyboard steering remains available.

Controller-family improvements included in this release:

• [b]DirectInput and HID support[/b] alongside XInput, with automatic Xbox, PlayStation, and Nintendo controller identification.
• [b]81 controller sprites[/b], including refreshed Xbox artwork, used throughout interaction prompts, native Controls rows, driving hints, and controller menus.
• [b]Saved controller-family override:[/b] choose Auto, Xbox, PlayStation, or Nintendo in Controller settings → General. A manual choice overrides detection until you select Auto again.
• [b]Optional driving hints:[/b] turn the seated helper box on or off in General settings.
• [b]More readable controller menus:[/b] centered uncommon-action captions, darker textured buttons, outlined pale text, and blue focus borders.

[size=4][b]Features[/b][/size]

• Analog movement, camera, steering, and independent throttle/brake triggers, plus clutch, ignition, shifting, handbrake, lights, and horn.
• Object pickup, movement, rotation, mounting, detachment, and distance adjustment. Rotation has its own speed setting.
• Menu navigation with the D-pad or left stick, right-stick virtual pointer, scrolling, and controller focus outlines.
• Save/Load navigation that prefers Save when available, skips informational fields, and keeps confirmations focused on No. RB focuses Save and LB returns to slots; cancel backs out of confirmations.
• Uncommon-actions menu for survival actions, tools, direct gears, camera functions, and system actions. Hold confirm for continuous actions, or toggle supported holds.
• Toggle sprint and crouch. Sprint cancels when movement stops.
• Separate editable on-foot/driving bindings, including buttons, triggers, stick directions, and combinations of up to three controls. Hints follow saved bindings.
• Saved camera, object movement/rotation, pointer, deadzone, inversion, and steering-response settings.

All 68 named game actions have controller routes. Survival also includes the native Defecate action, subject to the game's 30% bowel-meter requirement. Actions retain the game's normal restrictions. Text entry uses a physical keyboard; there is no on-screen keyboard.

[size=4][b]Requirements[/b][/size]

• The Long Drive [b]v2024.11.26b[/b]. The tested build reports 2024.11.26b_test.
• An Xbox/XInput, supported PlayStation/Nintendo, or compatible DirectInput controller.
• [url=https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5]BepInEx 5.4.23.5 Windows x64[/url], installed separately. Use the Windows loader on Windows and Linux/Proton.

The private Windows x64 SDL2 controller runtime is included. No additional native Linux library is needed under Proton.

[size=4][b]Installation and updating[/b][/size]

1. Close the game. Install BepInEx beside the [b]TheLongDrive.exe you actually launch[/b]. Linux/Proton users must configure the override below before launching.
2. Launch once to generate BepInEx configuration, then close the game.
3. [b]Required for this game:[/b] in BepInEx/config/BepInEx.cfg, under [Chainloader], set HideManagerGameObject = true and save.
4. Extract the mod archive into the same game folder. Copy the [b]whole[/b] BepInEx/plugins/LongDrive.Controller folder. It contains both LongDrive.Controller.dll and TLDControllerSDL2.dll, plus SDL license notices. The managed DLL alone is insufficient for DirectInput support.
5. Connect the controller and launch. Open uncommon actions with View/Back/Select/Minus, then press Start/Options/Plus for controller settings.

When updating from an older version, replace the complete plugin folder contents from the archive. Keep your configuration and any custom gamecontrollerdb.txt; the archive does not include or overwrite them. Keep only one copy of the mod installed.

[b]Linux / Proton / Faugus[/b]

For Steam, add WINEDLLOVERRIDES="winhttp=n,b" %command% to the game's launch options, preserving existing wrappers and overrides.

For Faugus or another Proton launcher, point it at the executable in the modded game folder. Add [b]WINEDLLOVERRIDES[/b] with the value [b]winhttp=n,b[/b]. Installing into a different game copy will not enable the mod in the copy you launch. Different Proton prefixes may have separate settings and saves.

See the [url=https://docs.bepinex.dev/articles/advanced/proton_wine.html]official BepInEx Proton guide[/url] for the equivalent winecfg setup.

[size=4][b]Controller families and quick controls[/b][/size]

The following defaults use Xbox names. In-game icons follow the selected family:

• Xbox A/B/X/Y correspond to PlayStation Cross/Circle/Square/Triangle.
• Nintendo uses its printed A/B/X/Y letters: A on the right confirms, B below cancels, X is upper, and Y is left.
• Xbox LB/RB/LT/RT correspond to PlayStation L1/R1/L2/R2 and Nintendo L/R/ZL/ZR.
• View/Back corresponds to PlayStation Select/Share and Nintendo Minus; Start corresponds to Start/Options and Plus. The shared PlayStation artwork uses Select/Start icons.

[b]Default Xbox controls:[/b] LS/RS move/look; LS click toggles sprint; B toggles crouch; A jumps; X uses/enters/exits; Y picks up/drops; RT/LT are primary/secondary actions. Hold LB+RB and move RS to rotate a held object. Driving uses LS steering, RT/LT throttle/brake, A handbrake, held B ignition, LB/RB shifting, and LS click clutch.

The included [b]CONTROLS.md[/b] covers modifiers, inventory, menus, bindings, and text entry.

In Controller settings, LB/RB switches General/Bindings. On General, select with up/down, adjust with left/right or +/−, confirm increases or toggles, and the upper face button restores defaults. [b]Controller family[/b] saves a manual icon choice across restarts and reconnections; choose Auto to restore detection. [b]Driving hint box[/b] hides or shows the seated helper without hiding other interaction prompts. General defaults restores Auto and enables driving hints; it does not reset bindings.

[b]Steering time to full lock[/b] is adjustable from [b]0.10 to 3.00 seconds[/b] in General. It limits how quickly steering approaches the stick target, rather than limiting maximum steering. Holding full stick still reaches full lock. Release returns gradually toward center, and full left-to-right reversal takes roughly twice the center-to-lock time. The setting also controls pointer-steering rate and saves automatically. General defaults restores 0.75 seconds. [b]Steering stick curve[/b] (0.25–2.00, default 1.00) separately shapes partial-stick input.

On Bindings, the left face button switches profiles, LT/RT changes categories, confirm begins capture, and RS click clears a binding. Release all controls before entering a new combination, then release again to save. Occupied bindings require swap confirmation. Start/View and menu navigation remain fixed for recovery.

[size=4][b]Detection and compatibility[/b][/size]

Known devices use their vendor identity, name, and SDL controller type. Unknown XInput devices use Xbox icons; unknown DirectInput/HID devices use PlayStation icons. If detection is wrong, choose a family manually. This setting changes icons; physical input remains normalized by SDL.

Steam Input and other mappers may expose a physical controller as a virtual Xbox device. Avoid simultaneous controller-to-keyboard mappings that cause duplicate input. Unmapped DirectInput devices use a conventional PlayStation-style fallback; unusual layouts may need an SDL mapping in gamecontrollerdb.txt beside the plugin. Device-specific USB/Bluetooth behavior is not universal.

This is a [b]beta[/b], tested interactively on Linux/Proton with an 8BitDo controller in Xbox, Nintendo, and generic DirectInput modes. Nintendo letter mapping and the PlayStation fallback prompts were confirmed during testing, as were manual family selection, driving-hint preferences, and centered action captions. Version 0.6.7 passes 1,554 core checks and 172 native input/UI/config checks under Proton, including an inactive fixture exercising the actual game steering method and saved steering-time reload. All 81 sprite identities were verified. These checks do not replace exhaustive vehicle-physics or driving-feel testing. Native Windows hardware and genuine Sony-controller hardware have not been independently tested. Other game versions, every vehicle/menu, multiplayer/VR activity, and third-party mod menus have not been exhaustively tested.

[size=4][b]Text entry, removal, and support[/b][/size]

Use a physical keyboard for custom save names and the in-game computer. The game provides default save names. RS moves the computer cursor, and cancel or Start exits it.

To uninstall, remove BepInEx/plugins/LongDrive.Controller; optionally remove the mod config. Keep BepInEx if other mods need it.

If the mod does not load, check the executable path, BepInEx installation, HideManagerGameObject, and Proton override. Look for [b]The Long Drive Controller 0.6.7[/b] in BepInEx/LogOutput.log. If only XInput works, check that TLDControllerSDL2.dll is present and that the log does not report an SDL runtime failure. If icons are wrong, select Controller family manually or return it to Auto.

For support, include game/mod versions, OS/Proton, controller model/mode, Steam Input setup, the failed action, and the log. After reconnecting or changing contexts, release all controls to neutral before resuming gameplay.
